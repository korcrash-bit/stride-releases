# STRIDE Android 배포

STRIDE 앱의 Android 설치 파일과 배포 안내를 제공하는 저장소입니다. 앱 소스는 별도 비공개 저장소에서 관리합니다.

## 현재 상태

APK 릴리스 게시를 준비 중입니다. 아직 다운로드할 수 있는 릴리스는 없습니다.

- 준비된 버전: **0.3.2**
- Android 8.0 이상, 패키지 `kr.stride.workout`
- 검증된 APK 크기: **3,605,382 bytes**
- SHA-256: `0901e7850c79dc3d278cdb586db724d2b4f27256ba36007df1ee057fd17a47f4`

릴리스가 게시되면 GitHub Releases의 `STRIDE-0.3.2.apk` 파일을 휴대폰에서 내려받아 설치할 수 있습니다. 실제 기기에서의 Google 로그인과 기록 조회는 아직 검증 전입니다.

웹 앱: https://stride-workout-log.lollorulru.chatgpt.site/

이 저장소에는 운동 기록, 로그인 토큰, OAuth 보안 비밀, 서명 개인키를 올리지 않습니다.
